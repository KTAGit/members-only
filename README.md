# Members Only

Members Only is an exclusive clubhouse web application where users can create accounts, log in, and share anonymous messages.

Visitors can view messages but cannot see who wrote them. Registered members can unlock access to authors names and publication dates by entering a secret passcode. Administrators also have the ability to delete messages.

## Features

- User registration and login
- Secure password hashing with bcrypt
- Authentication with Passport.js
- Membership access through a secret passcode
- Create and view messages
- Anonymous message viewing for non-members
- Member-only author and timestamp visibility
- Admin privileges for deleting messages

## Built With

- Node.js
- Express.js
- PostgreSQL
- Passport.js
- bcrypt
- EJS
- CSS

## Purpose

Built as part of The Odin Project curriculum to practice authentication, authorization, database relationships, session management, and role-based access control.
